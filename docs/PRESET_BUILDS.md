# PRESET BUILDS

## Regra de produto

Cada classe terá 8 Receitas oficiais.

A Receita 1 começa desbloqueada. As Receitas 2 a 8 são liberadas em sequência. Para liberar a próxima, o jogador usa a Receita oficial atualmente exigida e derrota o décimo adversário de uma campanha de IA.

Todas as cartas continuam liberadas desde o início. Uma Receita bloqueada bloqueia apenas o botão de montagem automática.

As listas abaixo definem os 8 arquétipos oficiais e uma Receita inicial completa para cada classe. As composições exatas das Receitas 2 a 8 devem ser congeladas depois do primeiro ciclo de playtest humano, para não transformar um balanceamento Alpha em conteúdo permanente.
